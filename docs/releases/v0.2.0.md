# Chezmoi Menu 0.2.0

macOS 27 以降・Apple Silicon 専用のリリースです。Intel と macOS 26 以前は対象外になります。

- SwiftUI のメニューバーパネルに進捗と停止ボタンを追加。
- 設定ウインドウを同期・差分・一般・OpenAI・実行履歴に整理。
- 現在の source と Mac の変更ファイル・差分を表示。除外対象は非表示。
- Download / Upload / 同期前チェックの macOS ショートカットを追加。
- Swift 6.4、actor、Observation、Swift Subprocess へ移行。
- 変更コマンドは停止要求があっても完了を待ち、未完了 merge を後処理。
- 統合前から未適用状態を記録し、停止後の再取り込みによる上書きを防止。
- Icon Composer の明暗に対応するレイヤー付きアイコン。

Apple Intelligence は使用しません。OpenAI の保存済みモデル・API key、アプリ設定と履歴は引き継ぎます。モデルの既定値は `gpt-6-luna` です。

配布ファイルは `Chezmoi-Menu-0.2.0-arm64.zip` と `.sha256` です。Developer ID 署名・Apple 公証済みのアプリを ZIP から展開し、同期していない状態で既存アプリを終了して置き換えてください。詳しくは [インストール手順](../INSTALL.md) を参照してください。

検証: macOS 27.0.1 / Xcode 27.1、隔離環境の Swift テスト 25 件、配布用 Python テスト 3 件。実際の dotfiles の書き換えや OpenAI API 課金を伴うテストは行いません。
