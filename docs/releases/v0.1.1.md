# Chezmoi Menu 0.1.1

別の Mac でもビルドせずに使える Universal 版を公開しました。

- macOS 14 以降、Apple Silicon / Intel の両方に対応。
- Developer ID 署名、Apple 公証、公証チケット添付。
- ZIP と SHA-256 チェックサムを配布。
- Download / Upload 同期、AI 競合解決、同期前チェックを利用可能。

`Chezmoi-Menu-0.1.1-universal.zip` をダウンロードして展開し、`Chezmoi Menu.app` を `~/Applications` または `/Applications` に置いて起動してください。

chezmoi と Git、dotfiles リポジトリ、Git 認証は各 Mac に必要です。AI 競合解決用の API key も各 Mac の設定画面で個別に保存します。設定後は最初に同期前チェックを実行してください。

[インストール手順](https://github.com/hshimomura/chezmoi-menu/blob/v0.1.1/docs/INSTALL.md)
