# Chezmoi Menu 0.3.0

source の未コミット変更の確認からコミット、送信前の差分確認までを GUI で行えるようにしました。macOS 27 以降・Apple Silicon が対象です。

- 「差分」で未コミット・コミット済みと upstream・Mac と source の比較を切り替え。
- メッセージを入力して source の全変更をまとめてコミット。コミット前にバックアップを保存。
- コミット後は upstream との差分へ切り替え、先行・遅延コミット数を表示。
- 暗号化 `.env` や除外パスもファイル名を表示。本文は非表示にし、AI に送信しない方針を維持。
- 複数ファイルの変更・追加・削除・名前変更に対応。本文を 100,000 文字で打ち切る場合も、全ファイル名とコミット対象を保持。
- 設定ウインドウのサイドバーにアプリのバージョンを表示。

コミット操作は source の全変更を対象とし、Mac 側の編集の取り込み・適用・送信は既存の同期操作で行います。送信する場合は Upload を実行してください。upstream 比較には最後に取得した状態を使用します。

既存のアプリ設定、OpenAI API key、モデル設定、履歴を引き継ぎます。age 秘密鍵と chezmoi の暗号化設定は各 Mac に用意してください。詳しくは [使い方](../USAGE.md)を参照してください。

検証: macOS 27.2 / Swift 6.4 / chezmoi 2.72.2 で Swift 38 件・配布用 Python 3 件が成功。隔離した Git / chezmoi 環境で、暗号化 `.env` の端末間同期、複数ファイルの差分・コミット・Upload、差分の表示上限を確認しました。実際の dotfiles を使った GUI の動作確認も利用者が実施済みです。
