# Chezmoi Menu 0.4.0

暗号化ファイルなどの競合時に、GUI でローカル／リモートのどちらを採用するか選べるようにしました。macOS 27 以降・Apple Silicon が対象です。

- 競合ファイルごとに「ローカルを採用」「リモートを採用」を選択。
- 「すべてローカル」「すべてリモート」で一括指定。未選択のまま続行せず、同期の中止にも対応。
- 暗号化・AI 除外対象などの通常ファイルは、内容を表示・AI 送信せず版を選択。API key なしでも利用可能。
- 通常の AI 競合解決との混在に対応。選択したファイル全体を採用し、競合していない変更は通常どおり統合。
- バックアップと両方の Git 履歴を保持。リポジトリ全体の reset や force push は行わない。
- 選択待ちの中止、source・Git index・ホーム側への外部編集を保護。複数ファイルが再編集された場合はすべてを退避。

「ローカル」はこの Mac の変更を取り込んだ source、「リモート」は今回取得した upstream の版です。選択後、Download はこの Mac に適用し、Upload は適用後にリモートへ送信します。削除された版を採用する場合は source の管理対象から外しますが、ホーム側に配置済みのファイルは残ります。

既存の設定、OpenAI API key、履歴を引き継ぎます。詳しくは [使い方](../USAGE.md)と [復旧手順](../RECOVERY.md)を参照してください。

検証: macOS 27.2 / Swift 6.4 / chezmoi 2.72.2 の隔離環境で Swift 49 件・配布用 Python 3 件が成功。競合選択画面も利用者による動作確認済みです。
