# データ保存と AI への送信

## この Mac に保存するもの

| データ | 保存先 |
| --- | --- |
| API key | macOS キーチェーン。service: `jp.local.ChezmoiMenu.openai` |
| アプリ設定 | `~/Library/Application Support/ChezmoiMenu/settings.json` |
| 実行履歴 | 同ディレクトリの `history.json`。直近 300 件 |
| バックアップ | 同ディレクトリの `Backups/` |

API key を設定 JSON や履歴に書きません。保存後の設定画面では空欄に戻し、既存キーを再表示しません。空欄で設定を保存するとキーを保持します。キーを削除する場合は macOS の「キーチェーンアクセス」で上記 service の項目を削除してください。

起動時や競合のない同期では API key を読み込みません。AI 解決が必要になった時点で取得します。ad-hoc 署名のアプリを再ビルドしたあと、macOS がキーチェーンへのアクセス許可を求める場合があります。

## ネットワーク通信

- Git: 設定済みのリモートに fetch / ls-remote / push を行います。Git の認証情報は既存の設定を使用します。
- OpenAI: AI 競合解決時に `https://api.openai.com/v1/responses` を呼びます。競合ファイルのパスと、共通祖先・ローカル・リモートの全文を送信します。

OpenAI のリクエストには `store: false` を指定します。これは外部サービス側のすべてのログ保存や保管期間を無効にする保証ではありません。取り扱いは [OpenAI のデータ制御](https://developers.openai.com/api/docs/guides/your-data) と利用中の API アカウントの設定を確認してください。

通常の Git merge で解消できる場合、AI を無効にしている場合、同期前チェック・差分表示では OpenAI API を呼びません。Apple Intelligence / Foundation Models は使用しません。

## AI 送信の制限

既定のパス除外は `encrypted_`、`private_`、`.env`、`dot_env`、`.ssh`、`dot_ssh`、`credential`、`secret`、`token`、`.pem`、`.key` です。大小文字を区別しない部分一致で判定します。`encrypted_` のファイルは設定変更にかかわらず自動解決しません。

除外は内容から秘密情報を検出する機能ではありません。許可するファイルに秘密情報を置かないでください。対応する競合は各版 48 KB 以下の通常ファイルの UTF-8 テキストです。

AI にファイル内容を命令として扱わせない指示を付け、構造化した応答、完了状態、拒否、空の統合結果、競合マーカーを検証します。chezmoi の apply 予行も行いますが、一般の設定ファイルの意味やシェル構文をすべて検証するものではありません。

## 実行権限と記録

App Sandbox を使用せず、ユーザー権限で chezmoi / Git を実行します。chezmoi の既存設定やテンプレート、Git hooks などは信頼できるものを使用してください。chezmoi scripts は既定で apply 対象から除外します。

履歴にはステップ名や件数、バックアップ名などを記録します。API key、HTTP 本文、dotfiles の内容やコマンドの生出力は記録しません。外部コマンドの出力は非同期パイプからメモリへ取得し、stdout は 16 MiB、stderr は 1 MiB に制限します。バックアップにはファイルの内容を保存するため、履歴とは異なる扱いが必要です。

差分表示はローカルの現在の source と Mac を比較します。AI の除外パスと暗号化パスは内容を読み込む対象から外し、差分本文は最大 100,000 文字をメモリ上だけで表示します。履歴・設定ファイルへ差分を保存しません。一般のファイル内に含まれる秘密を検出・墨消しする機能ではありません。

不具合報告では API key、Git 認証情報、秘密の dotfiles、バックアップ全体を公開しないでください。再現用の架空データと必要なエラー概要を使ってください。
